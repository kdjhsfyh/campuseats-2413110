# Week 1 Reflection



# 1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?



imperative means telling the browser what to do step by step, while React describes how the UI should look



# 2. Why must a component name start with a capital letter?



so react can recognise it as a custom component



# 3. What does a fragment <>...</> do, and why not just use a `<div>`?



fragment groups elements without adding an extra element to the page



# 4. Name one benefit of splitting the UI into small components



it makes the code easier to understand and reuse
